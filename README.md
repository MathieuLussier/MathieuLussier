## 🌟 Featured Project

### ♟️ [Multiplayer Chess Arena](https://github.com/MathieuLussier/multiplayer-chess-game)
A beautiful, real-time multiplayer chess game built within a TypeScript monorepo.
- **Real-Time Multiplayer:** Instant move synchronization via websockets.
- **Strict Server Authority:** Complex chess rules (check, checkmate, stalemate) processed and validated on the backend.
- **Premium UI:** Glassmorphism aesthetics with dynamic move histories and interactive lobby matchmaking.
